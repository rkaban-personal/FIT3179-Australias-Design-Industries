# Behind everyday design

An illustrated field guide to Australia’s design industries by Reynard Andyti Putra Kaban, FIT3179, Monash University Malaysia.

The single scrolling page contains 13 Vega/Vega-Lite charts. All runtime assets, fonts, datasets and readable chart specifications are included in this repository. No API key, account or external chart CDN is required to view the site.

Read [About the data](audit-summary.html) and the per-chart source notes for definitions, transformations and limitations. [The chart manifest](chart-manifest.json) maps each chart to its data and specification. Third-party library and font licences are included in `assets/`.

For a local preview, run `python3 -m http.server 4179` in this directory and open http://localhost:4179/. For GitHub Pages, publish the main branch’s root folder and retain `.nojekyll`.
